# Jian’s Chili website

Static homepage for GitHub Pages.

## Before publishing

1. Push the contents of this folder to the publishing branch of your GitHub Pages repository.
2. In GitHub, enable Pages for that branch and set the custom domain to `www.jianschili.com`.
3. At your domain registrar, point `www` to `<your-github-username>.github.io` with a CNAME record. Add GitHub Pages’ four A records for the root domain if you also want `jianschili.com` to work without `www`.

The included `CNAME` file tells GitHub Pages to serve the site at `www.jianschili.com`.
